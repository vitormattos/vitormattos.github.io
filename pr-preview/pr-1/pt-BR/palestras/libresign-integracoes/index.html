Sobre esta palestra

Esta apresentação introduz o LibreSign dentro de um contexto mais amplo de software livre, privacidade e soberania tecnológica. Ela aborda a integração com o Nextcloud, a arquitetura de assinatura e API do projeto, a integração do LibreSign com o GLPI e os desafios técnicos e comunitários de manter uma plataforma livre de assinatura eletrônica.
