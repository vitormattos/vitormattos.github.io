# Free software as infrastructure

Vitor Mattos

---

## Publishing code is only the beginning

A public repository matters, but sustainable free software also needs maintenance, review, documentation, governance and people.

---

## Code becomes infrastructure when others can depend on it

- predictable releases
- documented decisions
- compatibility and migration paths
- security response
- contribution workflows

Notes:
These are examples of work that is often invisible when people evaluate a project only by its repository.

---

## Community changes the nature of a project

Users report problems. Contributors propose changes. Maintainers review them. Decisions become visible and reusable.

---

## Sustainability is part of engineering

Free software does not mean that maintenance has no cost.

Projects need time, people and financing without compromising software freedom.

---

## From code to infrastructure

The source code is the visible artifact.

The long-term value comes from the technical and social structures that keep it useful.
